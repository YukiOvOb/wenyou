# 长夜书局

一个在手机浏览器里玩的 AI 文字冒险引擎。整个游戏就是一个 `index.html`，不需要服务器。

在线地址：https://yukiovob.github.io/wenyou/

## 开始玩

1. 打开网页，点右上角「设置」，填入 DeepSeek（或其他兼容 OpenAI 格式的）API 密钥，点「测试连接」。
2. 回到书架，选一个剧本，点「开始新游戏」。
3. 手机浏览器里选「添加到主屏幕」，用起来就像一个 App。

密钥、存档、偏好都只保存在你自己的浏览器里。换设备或清理浏览器数据之前，记得在「设置 → 数据」里备份。

## 更新

网页发布新版本后，打开着的页面顶上会出现「网页有新版本 · 更新」，点一下就行，存档和设置都还在。也可以在「设置 → 版本」里看当前版本、手动检查更新。

## 内置剧本

- **斗罗大陆 · 武魂殿之女**：唐家三少《斗罗大陆》同人。从武魂殿一侧经历原著的时间线。开局时主角的出身、起点、武魂、天赋、名字、性格每一项都可以从预设里挑、🎲 随机抽，或 ✨ 让 AI 现编一个新的。
- **雾港来信**：短篇民国悬疑，演示用。

## 设置放在哪里

- **剧本设置**（书架上剧本卡片的「剧本设置」、开局页、游戏内「玩法」页）：篇幅、节奏、故事口味、文风、是否使用基础偏好。每个剧本各自保存，这个剧本的所有存档共用。
- **全局设置**（右上角齿轮）：API、基础偏好、口味方案库、文风库、写作习惯、记忆参数，以及剧本设置选“跟随全局默认”时使用的默认值。
- **本局设定**（游戏内「玩法」页下半部分）：主角性格、身世、对接下来剧情的要求，只属于当前存档。

## 引擎怎么记住剧情

每回合发给 AI 的内容包括：剧本设定、人物卡（含只给 AI 看的隐藏设定）、关键事件、目标、物品、剧情摘要、最近几回合的原文，以及只给 AI 的主线时间线与蝴蝶效应备忘。原文超过一定回合数后，较早的部分会自动压缩进剧情摘要，所以玩得再久，上下文长度也基本不变。

## 写自己的剧本

剧本是一个 JSON 文件，可以在书架上「新建剧本」得到模板，或参考 `scripts/douluo-wuhundian.json`。

剧本里的文字每回合都会发给 AI，AI 会模仿它的口吻，所以用你想读到的那种文风来写，写清楚“是什么、要怎样”。AI 哪里写得不对，就回头把对应的设定写清楚。

主要字段：

| 字段 | 作用 |
|---|---|
| `world` | 剧本正文：世界观、背景、人物关系、暗线。每回合完整发给 AI。 |
| `rules` / `style` | 剧本规则与默认文风。 |
| `stats` | 主角属性表（数值或文本）。 |
| `characters` | 人物卡。`motive` / `backstory` / `secret` 只给 AI 看；`address` 写别人怎么称呼这个人物；`met: false` 表示主角尚未结识。 |
| `creation` | 随机开局表：每个字段是一组带权重的预设选项，可以设置属性、追加人物、覆盖人物关系、指定起始阶段与开场要求。`ai: true` 时每个字段旁会出现 ✨ 按钮，`aiGuide`（总体要求）和字段的 `aiHint` 告诉 AI 怎么现编新选项。 |
| `length` / `pace` / `defaultProfile` / `style` | 剧本设置的默认值（玩家可以在剧本设置里改）。 |
| `milestones` | 主线节点（只给 AI 看），AI 会按顺序推进，并记录与原著不同的“蝴蝶效应”。 |
| `opening` / `openingGuide` | 固定开场白；留空则由 AI 按 `openingGuide` 与起点选项生成开场。 |
| `openingSeeds` | 开场情境库。AI 写开场时，每次随机抽一个情境（再配上随机的时间和基调），让每一局的开头都不一样。 |
| `version` | 剧本版本号。改了剧本、把版本号加一，已有的存档会提示同步新版本。 |

`tools/build_douluo.py` 是斗罗剧本的生成脚本，改完运行 `python3 tools/build_douluo.py` 即可重新生成 JSON。
