# 剧本文字写法（设定资料体）

写内置剧本、改剧本、给引擎加会发给 AI 的文字之前，先读这一份。

## 为什么要改

内置剧本里的世界观、规则、人物卡、开局选项，每回合都原样发给 DeepSeek。这些文字是 Claude 写的，带着 Claude 的叙述习惯。
DeepSeek 读了就模仿，写出来的剧情一股 Claude 味，比如“另一半只能等它自己长出来”“他不说，但心里门清”。
玩家要看 DeepSeek 自己原本的文风。所以剧本文字写成**不带任何叙述腔调的设定资料**，让 DeepSeek 没有可模仿的口吻。

写这些文字的是 Claude。Claude 写中文时的本能（反差、留白、收尾点题、“其实”、知而不言、警句）正是要避开的东西。每写一句，对照下面的清单。

## 目标文体：设定资料体

像设定集、人物资料卡、百科词条那样写。

- 每句只陈述事实：谁、是什么、在哪、什么时候、和谁什么关系、想要什么、做过什么、知道什么、有多少。
- 按时间顺序或按项目排列。句子完整、通顺，用最普通的词。
- 不做文学处理：不制造转折、悬念、留白、反差、余味，不点题，不评论。
- 所有事实都保留：人名、地名、数字、价格、年份、境界、关系、谁知道什么谁不知道什么、秘密的内容、剧情钩子。改的只是写法。
- 同人剧本的事实以原著为准。

### 各字段的写法

| 字段 | 写法 | 例子 |
|---|---|---|
| personality 性格 | 顿号分隔的特征短语，4～8 项，每项 2～10 字。两面性就并列两项特征。 | “慵懒、随性、看人极准、很少发火、发火时很可怕” |
| appearance 外貌 | 顿号分隔的短语 | “看起来三十岁上下、红衣、眼尾一点朱砂” |
| opinion 看法 | 第三人称描述对主角的态度，15 字以内。不写成人物说的话。 | “不认识主角”“把主角当自家孩子，很疼她”“觉得主角还没开情窍” |
| brief 简介 | 一句事实 | “合欢宗宗主，修情道近八百年。” |
| motive / backstory / secret | 事实陈述，按时间顺序 | 见下面的例子 |
| address 称呼 | 原样保留（已经是资料体） | |
| relation 关系 | 原样保留，除非有修辞 | |
| now 现状（新增） | 故事开始这一刻，这个人在哪、在做什么、和谁在一起、处在自己经历的哪一步。30～70 字。只写他自己的处境，不写他和主角的关系（那由开局决定）。 | “和谢无霜奉命到青石镇查年轻男子接连死亡的案子，住在镇上的客栈。” |

### style 怎么处理

`style` 改成 `""`。原 style 里如果有“要交代哪些信息”的内容要求（例如“战斗写清楚魂环颜色、魂技效果”“直播场景有弹幕和礼物特效”“朝堂、宴席、密室这些场景，写清楚在场有谁”），而 rules 里还没有，就在 rules 末尾加一条平实的规则，写成这个世界的规矩或游戏需要的信息，例如“战斗时交代双方用了哪个魂环的哪个魂技。”
讲句子长短、用词、克制、潜台词、细腻、让读者自己体会、话中话、节奏轻快之类写法的内容，全部删掉，不搬进 rules。

### 文件开头 docstring 里“写剧本的原则”第 1 条

改成：“这里的文字每回合都会发给 AI。写成设定资料：只写事实，不带叙述腔调和修辞，免得 AI 模仿写这些字的人的口吻。文风交给 AI 自己。”
（只有含 docstring 的那一片需要改。）

## 要避开的写法（例子都来自 2026-09-29 改写前的旧文字）

1. **知而不言**：“从来没说破”“他不说，但……”“……，她知道，但没法回应”“心软的时候自己都不知道”“嘴上不说”“心里门清”。→ 直接写事实：“知道 X。没有告诉 Y。”“知道焱喜欢她，不打算回应。”
2. **表面 / 其实**：“看着没心没肺，其实……”“心思其实很细”“他其实很怕在她面前输”“表面上……”。→ 并列特征，或直陈：“怕在胡列娜面前输。”（“表面身份是……”这种讲身份伪装的事实可以保留。）
3. **不是 X，是 Y**：“不是为了害宗门，是为了给旧姐妹赎身”“与其说……不如说”。→ 直陈：“用这些灵石给青楼里的旧姐妹赎身，无意害宗门。”
4. **收尾意象、留白、余味**：“她不记得爹娘的样子，只记得那年冬天很冷。”→ “不记得父母的样子。”
5. **警句、格言、概括人生的判断**：“放不下，就突破不了”“钱能买到很多东西，也有买不到的：真心、尊重、别人的过去”“每个接近主角的人，都有自己的理由”“没有一天为自己活过”“愿意白给穷人东西的地方不多”。→ 改成事实，或删掉。
6. **倒装、延迟揭示**：“当年把{name}送人的主意是她父亲出的，放{name}逃走的，是她。”→ “把{name}送人是父亲的决定。{name}逃走那晚，是她放走的。”
7. **夸张的具象描写**：“发起火来整座山都安静”→ “很少发火，发火时很可怕”。
8. **对仗、排比、成组的“可以……也可以……”**：“她可以真心，也可以骗人；可以爱一个人很久，也可以转身就走”→ “她对感情很随性，真心和欺骗都有可能，爱得久也可能随时离开。”或者直接合并进特征列表。
9. **人物口吻的台词**：opinion 里的俏皮话（“这孩子，心还没开。”“丫头又瘦了。”“我养大的孩子，我知道。”“还不认识你。”）→ 第三人称描述（“不认识主角”）。
10. **“越……越……”式格言**：“嘴上越没正形，心里越怕被人看不起”→ “自卑，怕被人看不起；爱开玩笑掩饰”。
11. **带情绪的转折词做修辞**：好在、偏偏、却、竟、只是、终究、到底、原来。→ 删掉或换成中性连接。
12. **句末补一小句感叹或点题**：“……。他也会失败。”这种单独拎出来强调的短句 → 并进前一句或删掉（事实本身要留）。
13. **比喻**：凡是比喻都改成直说。

## 引擎自己的提示词

- 系统提示、篇幅节奏、生成身世 / 性格 / 选项 / 摘要的提示词，只写功能：视角、格式、要交代的信息、字数、停在哪里。
- 不写文风和写作手法（平实、克制、潜台词、让读者体会、用具体细节……）。文风只来自玩家自己选的文风或写作习惯。
